## 5. 重要陷阱（都是踩過的，別再踩）

1. **行情 API 回聲陷阱**：TWSE／TPEx 行情 API 對休市日會「回顯請求日期、回傳最近交易日的資料」（10-23 颱風假實測：1,088 筆收盤與 10-22 完全相同）。**不得**用行情 API 反證某日有交易。
2. **台股休市判定**：以「台北市是否宣布全天／上午停班」為準（行政院人事行政總處公告）；正式開休市表以 TWSE／TPEx 公告為準。颱風休市是臨時公告，用 `mark_market_closed()` 記為 `user_confirmed/manual`——現有兩筆（07-10、10-23）都正確，**不要「修正」它們**。
3. **測試不得開網路**：`conftest.block_network` 會讓 TCP connect 直接 raise；要打網路的測試必須標 `live` 並 mock client。
4. **CI 的文件建置只在 3.14 跑** `sphinx-build -W`：改 docstring（RST）後要在本機跑同一條命令；清單前要空行、inline literal 後別緊貼全形標點。
5. **兩條入口共用同一功能時，只驗其中一條等於沒驗**（CLI／TUI 掃描落庫事故的教訓）。
6. **改 `.py` 前先確認影響面**（LSP 或 grep）；單檔 ≤1200 行；Python 3.13 相容——多例外一律 `except (A, B):`，禁用 3.14-only 語法。
7. **不要把套件目錄加進 sys.path**（會造成 `db` 模組分裂）；一律 `python -m twstock.main`。
8. **Windows console 中文亂碼**是顯示問題，檔案是 UTF-8；驗證看 DB 狀態或 `--json`，不要拿 console 中文字串斷言。
9. `migrate_db()` 只在需要升版時才備份（2.3GB）；目前 v18，不會觸發。
10. push／merge／schema 變更／刪檔需所有者授權（本輪授權紀錄見 archive 任務文件）。
