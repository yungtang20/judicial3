# 財物取得與毀損家族題庫

- `family_id`：`property_acquisition_and_damage`
- 文件狀態：`DESIGN_DRAFT`
- Runtime：`DISABLED`
- Human Gate：所有權、持有、授權、不法所有意圖、告訴條件、行為時法與最終罪名均須人工審核。
- 來源：`data/question_bank.json` 的竊盜、加重竊盜、侵占、毀損要件；`../questions/theft.md`；`review/property-taking-issue-matrix.md`。

## 一、家族範圍

本家族處理財物特徵與價值、所有與持有關係、取得或接觸方式、授權範圍、後續處分及損壞結果。強暴、脅迫或不能抗拒的細節只作為切換至「意思壓制」家族的線索，不在本家族直接決定搶奪或強盜。

| 代碼 | 內部 child route 方向 |
|---|---|
| 竊 | `theft_320_1_movable` |
| 加 | `aggravated_theft_321` |
| 侵 | `embezzlement_335_general`、`embezzlement_336_1_public`、`embezzlement_336_2_business`、`embezzlement_338_applicable` |
| 遺 | `embezzlement_337_lost_property` |
| 損 | `damage_352_document` 至 `damage_357_complaint` |
| 全 | 上述各方向共用；不是同時成立的意思 |

## 二、通用層處理

人別、權利告知、自由陳述、一般證據、有利證據及結尾題由 common layer 提供。本檔仍保留部分來源列以便閱讀，但有 `common_owner_ids` 的題目未來不得重複 materialize。

## 六、條件分支模組

### P-E1 一般取走分支（觸發：財物原在他人控制下，且有未經授權取得或移動的主張）

| 編號 | 問句 | 對象 |
|---|---|---|
| P-E1-1 | 財物在被取得前的具體位置及控制方式為何？ | 全部 |
| P-E1-2 | 行為人如何使財物離開原持有人的實際控制？ | 全部 |
| P-E1-3 | 行為人取得財物後是否排除原持有人使用或取回？具體情形為何？ | 被害人、涉嫌人 |
| P-E1-4 | 若主張只是暫時使用，預定何時、如何及在何條件下返還？ | 涉嫌人 |

### P-E2 加重取得方式分支（觸發：有侵入、毀越、器械、多人、災害或交通場站線索）

| 編號 | 問句 | 對象 |
|---|---|---|
| P-E2-1 | 行為人如何進入住宅、有人居住的建築、船艦或物品所在空間？ | 全部 |
| P-E2-2 | 門窗、牆垣、鎖具或其他安全設備原本及事後狀態為何？ | 被害人、證人 |
| P-E2-3 | 當時攜帶或使用哪些器械？其用途與實際使用方式為何？ | 全部 |
| P-E2-4 | 現場共有幾人？各自在事前、現場及事後做了什麼？ | 全部 |
| P-E2-5 | 當時是否發生火災、水災或其他災害？與接觸財物有何時間、地點關係？ | 全部 |
| P-E2-6 | 事件地點是否在車站、港埠、航空站或公眾運輸工具內？具體位置為何？ | 全部 |

### P-E3 原合法持有／侵占分支（觸發：行為人原因保管、借用、委託、業務或公務關係合法持有）

| 編號 | 問句 | 對象 |
|---|---|---|
| P-E3-1 | 財物最初如何交付？交付目的、期限、權限及返還約定為何？ | 被害人、涉嫌人 |
| P-E3-2 | 是否因業務、公務或公益關係持有？職務內容及管理權限為何？ | 全部 |
| P-E3-3 | 何時出現逾越原授權的使用、移轉、出售、隱匿或拒絕返還行為？ | 全部 |
| P-E3-4 | 對返還要求、結算或盤點差異，各方當時如何回應？ | 全部 |
| P-E3-5 | 有無契約、交付清單、帳冊、盤點、催告或通訊紀錄可核對？ | 全部 |

### P-E4 遺失物／離本人持有物分支（觸發：行為人主張拾得，或財物曾離開原持有人直接掌握）

| 編號 | 問句 | 對象 |
|---|---|---|
| P-E4-1 | 財物最後由原持有人放置或使用的位置為何？當時是否仍能返回取回或遠端控制？ | 被害人、證人 |
| P-E4-2 | 財物是否由場所管理者、員工或其他人實際看管？有哪些管理措施？ | 全部 |
| P-E4-3 | 行為人何時、何地、以何種狀態發現財物？當時如何判斷來源與所有人？ | 涉嫌人、證人 |
| P-E4-4 | 發現後是否尋找失主、交付管理者或警察，或另行使用、隱匿、出售？ | 全部 |

### P-E5 毀損分支（觸發：財物仍在但有外觀、功能、效用或價值受損主張）

| 編號 | 問句 | 對象 |
|---|---|---|
| P-E5-1 | 財物受影響前後的外觀、功能、效用與價值差異為何？ | 全部 |
| P-E5-2 | 何人以何種動作、工具、物質或其他方式使財物發生變化？ | 全部 |
| P-E5-3 | 財物目前能否正常使用？可否修復，修復內容與費用依據為何？ | 被害人、證人 |
| P-E5-4 | 行為人當時知道財物屬於誰，以及其行為可能造成何種變化嗎？依據為何？ | 涉嫌人 |
| P-E5-5 | 若涉及文書、建築物、債權或詐術造成損害，具體標的、權利及損害如何發生？ | 全部 |

### P-E6 特殊客體分支（觸發：標的是不動產、能量、文書、建築物或債權）

| 編號 | 問句 | 對象 |
|---|---|---|
| P-E6-1 | 標的是可移動財物、土地建物，還是電能、熱能或其他能量？依據為何？ | 全部 |
| P-E6-2 | 若涉及土地或建物，原本使用、占有、界址及排除他人使用的方式為何？ | 全部 |
| P-E6-3 | 若涉及能量，取得設備、計量方式、使用期間及數量如何確認？ | 全部 |
| P-E6-4 | 若涉及文書、建築物或債權，權利內容、原始狀態及受影響結果為何？ | 全部 |
