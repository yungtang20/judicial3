# 公共危險交通家族題庫

- `family_id`：`public_danger_traffic`
- 文件狀態：`DESIGN_DRAFT`
- Runtime：`DISABLED`
- Human Gate：檢測程序、數值與單位、不能安全駕駛、傷亡因果、知悉事故死傷、離場、無過失減免、前案確定及行為時法均須人工審核。
- Scope：僅限 `public_danger_185_3_impaired_driving` 與 `public_danger_185_4_hit_and_run`，不代表公共危險章其他條文已建立題庫。
- 來源：`../questions/drink-driving.md`、兩條 route 歸檔工作單、`data/question_bank.json`。

## 一、家族骨架

共同確認交通工具、實際駕駛、時間與路線、飲酒或用藥時間軸、事故及傷亡、檢測與觀察來源、事故後行為。酒精或毒品資料存在，不單獨等同不能安全駕駛；事故或離開現場，也不單獨等同第185條之4成立。

| 代碼 | 精確 child route |
|---|---|
| 酒毒 | `public_danger_185_3_impaired_driving` |
| 肇逃 | `public_danger_185_4_hit_and_run` |
| 全 | 兩條 route 的共用交通事實；不是兩罪同時成立 |

## 二、通用層與專用表單

人別、權利告知、自由陳述、有利證據及結尾題由 common layer 提供。酒測、採尿／採血、交通事故處理、車輛移置與告知程序仍應使用機關正式表單；本家族題庫只補齊事實，不取代法定程序或表單欄位。
