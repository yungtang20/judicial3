## 閱讀順序

1. 先看通用層，確認人別、權利、自由陳述、證據與結尾題不重複。
2. 再看家族骨架，確認同類案件共用的事實問題。
3. 最後看 child route 補強與條件模組；它們不能被當成已確認罪名。
