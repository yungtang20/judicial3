# 組織證據論證鏈

## 目標

產出結構化圖譜，供承辦人審閱，**不下定罪結論**。

## 輸入

- 案件中性事實摘要
- 當事人主張或候選法條要件
- 既有證據清單（種類、來源、待證事實）

## 步驟

1. 列出總主張／子主張（或候選罪名／請求權的構成要件）。
2. 每個要件下列：待證事實、對應證據、證明力初評（強／中／弱／無）。
3. 標示**證據缺口**與建議補強方向（可接問句生成）。
4. 若涉及具體法條，先經 `search-taiwan-laws` 確認要件文字。
5. 輸出末尾：輔助草稿、需人工審閱；不宣稱「已證明」或「罪證確鑿」。

## 輸出結構建議

```text
主張／候選
├── 要件 A
│   ├── 待證事實
│   ├── 證據 …（證明力）
│   └── 缺口：…
└── …
```

可對照專案 Python 模組 `evidence_argument_chain` 的欄位命名，方便之後匯入工作台。
