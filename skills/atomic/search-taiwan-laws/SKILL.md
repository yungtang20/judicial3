# 查詢台灣法規（強制 MCP）

## 步驟

1. 整理使用者關鍵字或條號（可含簡稱：如個資法、家暴法）。
2. **呼叫工具**：
   ```
   taiwan_law_mcp___search_taiwan_laws
   參數：query（必填）、article_number（可選）、limit（建議 3–5）、include_history（需要沿革時 true）
   ```
3. 根據回傳結果整理：法規名稱、條號、條文要旨、source_url、是否現行。
4. 若工具失敗或無結果：明確寫「未檢索到／工具不可用」，標 `[待檢索]`，給建議改寫關鍵字。
5. 輸出中**必須**附 source_url，並提醒使用者核對最新版本。

## 輸出範本

```markdown
### 檢索結果（法規）
- 法規：…
- 條號：…
- 要旨／重點：（依 MCP 回傳摘要，勿擴寫未出現的內容）
- 來源：{source_url}
- 狀態：現行／請人工核對最新修正

（若無結果）未自全國法規資料庫檢索到符合項目。[待檢索]
```

## 禁止

- 未呼叫 MCP 就寫出「第〇條規定…」
- 把舊法或訓練資料當成現行法
