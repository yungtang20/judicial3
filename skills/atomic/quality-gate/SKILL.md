# 品質閘門（Verification）

在交付任何「法條引用、候選分析、證據鏈、筆錄草稿」前執行本檢查。

## 檢查清單

1. **法源真實性**：每一處條文／裁判／解釋是否有 MCP 回傳或明確 `[待檢索]`？
2. **角色邊界**：是否出現自動定罪、確定成立／排除用語？應改為 NEED_REVIEW／候選。
3. **草稿標註**：是否有「輔助草稿，需人工審閱」？
4. **敏感資料**：是否避免不必要落地姓名、完整案號於可外送摘要？
5. **禁止結論**：對照專案 `forbidden_conclusions` 精神，避免越權表述。
6. **可追溯**：關鍵主張能否對應到事實摘要或證據項？

## 結果

- **通過**：可交付，仍標草稿。
- **不通過**：列出缺口，要求補 MCP 呼叫或改寫後再交。

此 skill 對應 pstack 的 verification 地基：沒有可觀察驗證，就不上信任階梯。
